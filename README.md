# 智慧中医 — 基于大语言模型和中医资料库的家庭养生小助手

一个基于大语言模型（LLM）与中医药专业知识相结合的智能家庭养生助手，支持用户以自然语言进行中医健康问答，并提供八段锦、太极拳等养生教学视频。

## 项目简介

智慧中医将传统中医药知识与现代人工智能技术相融合，通过接入讯飞星火大模型，为用户提供专业的中医养生咨询和健康指导。用户只需在网页中输入问题，即可获得基于中医理论的智能回答。

## 功能特性

- **AI 中医问答** — 基于讯飞星火大模型，回答用户关于中医药和养生的各类问题
- **八段锦教学** — 内置八段锦教学视频，帮助用户练习传统养生功法
- **太极拳教学** — 内置太极拳教学视频，辅助用户掌握太极动作要领
- **网站介绍** — 简要介绍平台的理念与使用场景

## 技术栈

| 技术 | 用途 |
|------|------|
| Python 3 | 后端语言 |
| Flask | Web 框架 |
| Jinja2 | 模板引擎 |
| OpenAI SDK | 调用 LLM API |
| 讯飞星火 API | 大语言模型后端（模型: generalv3） |
| Bootstrap 5 | 前端 UI 框架 |

## 快速开始

### 环境要求

- Python 3.7+
- pip

### 安装依赖

```bash
pip install flask openai
```

### 启动应用

```bash
python app.py
```

浏览器访问 `http://127.0.0.1:5000` 即可使用。

## 注意事项

- 调试模式（`debug=True`）仅适用于开发环境，生产部署请关闭
- API 密钥目前为硬编码，部署到生产环境前应改为环境变量
- 视频文件较大（共约 55 MB），建议生产环境使用 CDN 或流媒体服务
